`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — an original one-line roast of a smart fridge that refuses to open after midnight. The output is deterministic: every run produces byte-identical output.

> My fridge after midnight: 'We're closed.' It's my fridge, it's my food — and it still carded me.

## Run it

```sh
python3 main.py
```
